# Saint-Valentin

Petite page web pour demander à quelqu'un d'être sa Valentine.

- Cliquer sur **Nunh uh !** affiche un nouveau message à chaque refus et fait grossir le bouton **AVEC JOIE**. Quand les messages sont épuisés, le bouton de refus disparaît.
- Cliquer sur **AVEC JOIE** remplace la question par « Joyeuse Saint-Valentin » et affiche un nounours amoureux.

## Lancer le projet

Aucune installation : ouvrir `index.html` dans un navigateur.

## Structure

```
index.html   page
style.css    styles
app.js       interactions des boutons
image/       fond et GIF
```
